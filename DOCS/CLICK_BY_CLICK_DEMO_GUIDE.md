## 🟢 Step 0: How to Launch
1. Open the project folder: `C:\SmartCityX`
2. **Double-click `start.bat`** (or `run-gui.bat`).
3. Press `Enter` (or type `1`) to open the **Graphical User Interface (GUI)**.

## 🎯 Summary of Key Talking Points

| Topic | Key Formula / Answer |
| :--- | :--- |
| **Why Zero `java.util`?** | Built custom `MyArrayList`, `MyHashMap`, `MyMinHeap`, `MyQueue`, `MyStack`, `DisjointSetUnion` to demonstrate core data structure mastery. |
| **Bittu's Algorithm ($O(1)$)** | 65,536-dimensional bigram space with rolling updates: $\Delta(\text{dot}) = -P[\text{leave}] + P[\text{enter}]$, $\Delta(\|W\|^2) = -(2c_{\text{old}} - 1) + (2c_{\text{new}} + 1)$. |
| **Kasai's Invariant** | $\text{LCP}[\text{Rank}[i+1]] \ge \text{LCP}[\text{Rank}[i]] - 1$, guaranteeing $\mathcal{O}(N)$ total comparisons. |
| **Max-Flow Min-Cut** | Maximum $s-t$ flow equals the minimum capacity among all $s-t$ cuts ($\max \text{flow} = \min \text{cut}$). |
| **Vertex Cover 2-Approx** | Any valid cover needs $\ge |M|$ vertices; selecting both endpoints of maximal matching gives $|C| = 2|M| \le 2|C^*|$. |
